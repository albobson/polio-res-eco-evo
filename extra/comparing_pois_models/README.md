This analysis compares a version of the model where viruses enter cells via a Poisson distribution, using MOI as the rate, to the model presented in the manuscript, where viruses enter cells via a uniform binomial draw.

To run this script, run "run_pois_comp.sh".

Dependencies:

-   This script relies on a previous pipeline run having been completed (the main snakemake pipeline).

-   Inside of run_pois_comp.sh, make sure to replace the path to the conda environment with your own path, and update the email notification settings if desired.

-   If you have updated any parameters (including the date run) from the snakemake pipeline, those will need to be adjusted in the 250818_comparing_pois_models.R file. It is currently set to run with 40 cores, so adjust as needed.

With 40 cores, this analysis takes about two hours to run. This analysis will output the results into this folder. A small figure can be generated by combining these results with the .afdesign file.
