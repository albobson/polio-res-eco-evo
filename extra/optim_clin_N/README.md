This analysis assesses early clearance as a function of the initial host cell population size fed into the optimization pipeline (a supplemental figure).

To run this script, run "run_optim_n_analysis.sh". This will start a snakemake pipeline, where individual jobs will be submitted, and their results will be collated.

The scripts used for this analysis are in this directory. The results will be compiled and plotted in this directory as well.

Dependencies:

-   This script relies on a previous pipeline run having been completed (the main snakemake pipeline). Particularly, it will use the data generated by the pipeilne, so if any parameters have been changed, amke sure to match them in the snakefile script.

-   Inside of run_optim_n_analysis.sh, make sure to replace the path to the conda environment with your own path, and update the email notification settings if desired.

-   The number of cores to use can be adjusted in sim_clin_trial_param_estimates.R.

-   The number of jobs submitted at one time can be modified in snake_ne_analysis.sh.

Running both jobs at once (with each job using 40 cores), this analysis takes about three hours to run.
