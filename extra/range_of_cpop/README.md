This analysis assesses the percent of resistant infections as a function of both host cell population size and initial viral population size (a supplemental figure).

To run this script, run "run_cpop_range.sh". This will run the correct R script. All data generated will be saved in this directory, as will the results.

Dependencies:

-   This script relies on a previous pipeline run having been completed (the main snakemake pipeline). Particularly, it will use the data generated by the pipeilne, so if any parameters have been changed, amke sure to match them in the snakefile script.

-   Inside of run_cpop_range.sh, make sure to replace the path to the conda environment with your own path, and update the email notification settings if desired.

-   The number of cores to use can be adjusted 250810_cpop.R. Currently, it is set to 20 cores.

With 20 cores, this analysis usually takes 6 hours to run.
